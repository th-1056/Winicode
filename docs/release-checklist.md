# 发布检查表

当前准备版本：`0.1.0-beta.1`。仓库：[th-1056/Winicode](https://github.com/th-1056/Winicode)。下面的未勾选项目均需实际记录证据；构建通过后也应继续完成桌面验证。

本版已完成的检查与待测边界见 [0.1.0-beta.1 验证记录](validation-0.1.0-beta.1.md)。下表作为后续稳定版本的完整验收清单保留，尚未执行的项目不代表已经通过。

## 版本、来源与工具

- [ ] 项目 Version、`BuildInfo.Version`、CHANGELOG 和资产文件名一致；软件内仓库链接为 `https://github.com/th-1056/Winicode`。
- [ ] MIT 版权为 Winicode contributors；原始 Unicode 18.0.0 License V3、来源哈希及 .NET 许可完整分发。
- [ ] 记录源码提交与 `v<version>` 标签。CI 的草稿工作流仅接受与项目版本一致且已指向当前提交的标签。
- [ ] 使用 Windows x64、PowerShell 7、官方 .NET SDK 10.0.402 和 Inno Setup 7.1.0 x64。工具提前准备在约定目录或 PATH；脚本不安装工具。
- [ ] 结束并行源码编辑，运行 `scripts/test-packaging.ps1`、`scripts/build.ps1` 与 `scripts/package.ps1`。
- [ ] 保存构建日志、`release-manifest.json`、两份 `payload-manifest.json` 和实际工具版本。本地兼容编译器 6.7+ 的产物需单独注明来源。

## 资产与源码

- [ ] `dist/` 中有 EXE、ZIP、`SHA256SUMS.txt`，运行 `scripts/verify-release.ps1` 成功。
- [ ] 安装版暂存目录只有 `install-mode.json`，便携 ZIP 只有 `portable.flag`；两者均无个人配置、日志和测试主机。
- [ ] 首次无 SDK、无预装 .NET 的 Windows 11 x64 可离线运行两种包；记录系统构建。
- [ ] 明确写明签名状态。默认打包为未签名测试包；如引入签名，应在归档与 SHA-256 生成前签名并复核真实签名状态。
- [ ] `scripts/export-source.ps1 -ListOnly` 和源码导出通过；逐项检查导出目录、Git 暂存区和所有公开图片。
- [ ] 源码无 `.tools/`、bin/obj、dist、artifacts、内部计划、原始截图、私有快照、用户名、私人路径、证书或凭据。

## 安装、升级和卸载

在可回滚的独立 Windows 测试环境中保存每步结果。

- [ ] 普通用户安装，无 UAC 提权，默认目录正确，桌面/登录启动/完成后运行均默认关闭。
- [ ] AppId 始终为 `{5B1D09D9-5EAC-4D73-BC78-4F6F9E32A971}`，重装与升级只有一个卸载登记，开始菜单卸载入口可用。
- [ ] 新装时勾选登录启动与设置页行为一致；注销后重登确认 `--background` 静默进入托盘。
- [ ] 在设置中关闭自启动后升级仍关闭；在 Windows 启动应用页禁用后升级也保持禁用。安装器升级时不重放旧 startup task。
- [ ] vA 修改设置和词条后升级 vB：正常退出，配置与别名保留，安装目录一致，快捷方式选择保留。
- [ ] `beta.2` 升 `beta.10`、Beta 升稳定版成功；逆序降级受阻。校验同版本修复安装。
- [ ] 在安装前取消升级，个人数据和已安装文件保持可用；替换阶段发生错误时给出可解释结果，修复安装可恢复。
- [ ] 退出命令超时、程序文件占用或缺失时安装/卸载安全停止，提示可重试，不强制终止无关进程。
- [ ] 普通卸载与静默卸载保留个人数据，移除本安装拥有的自启动项、文件、快捷方式和卸载登记。
- [ ] 交互卸载明确选择删除数据后只清理已知设置、别名、备份和日志；未勾选默认保留。
- [ ] 安装目录额外放入无关测试文件后卸载，该文件保持完整；目录中的链接或个人数据不被递归误删。
- [ ] 便携版在可写目录运行和升级均保留 userdata；只读目录有可理解提示；便携自启动入口关闭。
- [ ] 同用户同时启动安装版与便携版时，只出现一个输入增强实例。

## 输入、隐私与显示

- [ ] 新版微软拼音中 U+、0 唤起、未上屏内容带入、每页五项、数字选字和显式码位连续输入正确。
- [ ] 取消检索与关闭面板不误吞普通输入，目标与焦点保持正确；部分发送或结果不确定时不自动重试。
- [ ] 反复开关面板 100 次，无崩溃、重复上屏和残留 hook。
- [ ] 分别记录记事本、浏览器、VS Code、Obsidian 的版本与通过情况；失败组合列入限制或默认排除。
- [ ] 完成 100%/150%/200%、屏幕边缘、混合 DPI 双屏、深浅色与高对比度验证。
- [ ] 首次引导、内存输入测试、设置持久化、损坏配置恢复、别名导入导出和退出重启通过。
- [ ] 日志/诊断不含按键、查询、剪贴板、测试文本、原始异常路径和完整窗口标题；用户预览后再导出。
- [ ] 断网时核心功能正常；手动更新检查只读固定仓库，打开受校验的 Release 页面，不自动下载执行。
