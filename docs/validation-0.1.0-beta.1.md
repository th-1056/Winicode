## 已知限制与后续验证

- 当前 IME 定位依赖 Windows UI Automation 的实际候选控件结构；Windows 更新后可能需要适配。
- 未在干净的虚拟机、其他 Windows 构建、混合 DPI 双屏、ARM64、管理员窗口、远程桌面和游戏输入中完成验证。附带运行时及其文件已经校验，干净系统实装仍是后续门槛。
- 本版交互验证以独立 WPF 测试输入框为主，记事本、浏览器、VS Code 和 Obsidian 尚未完成完整兼容矩阵。暂不承诺所有软件中的输入行为相同。
- 登录启动已验证条目开启、关闭及升级保留；真实注销重登后的行为未在本次工作会话执行。
- 首次预编辑刚出现时，极快连按可能早于候选识别。看到 U+ 按钮后按 0 可避开这个时间窗口。
- 临时输入缓冲不能完整恢复程序启动前的输入、粘贴创建的拼音和全部复杂鼠标编辑。
- 搜索框直接接收英文，中文查询目前通过粘贴输入。字形显示和控制字符的接受行为取决于字体与目标应用。
- 未签名测试包可能出现 Windows 安全提示。无需关闭系统保护；请先核对下载来源与 SHA-256。

本文件记录实际完成的检查，不将构建通过或后台 CI 通过等同于完整桌面兼容性认证。
