# 使用说明

Winicode 的首版目标为 Windows 11 x64、新版微软拼音。完整支持范围仍需桌面验证，当前限制见[故障排查](troubleshooting.md)。

## 安装与便携运行

从[项目 Releases](https://github.com/th-1056/Winicode/releases)下载维护者公开的 EXE 或 ZIP，并核对同一版本 `SHA256SUMS.txt`。准备阶段可能尚无公开包。PowerShell 可使用 `Get-FileHash -Algorithm SHA256 -LiteralPath '.\Winicode-Setup-0.1.0-beta.1-win-x64.exe'` 查看本地哈希。

安装版默认位置为 `%LOCALAPPDATA%\Programs\Winicode`，以当前用户普通权限安装。安装器提供协议、安装位置、开始菜单、可选桌面快捷方式、登录启动和安装后打开程序。桌面快捷方式、登录启动和完成后运行均默认关闭。开始菜单同时提供卸载入口。

便携版需完整解压到当前用户可写的目录，再运行 `Winicode.exe`。请保留同级 `portable.flag`、运行时 DLL、`data/` 和许可文件。个人数据存于 `userdata/`。请关闭程序后再复制或移动整个便携目录；目录只读时，先将它移到可写位置。

两种分发包含 .NET 运行时，可离线运行核心功能。`install-mode.json` 标识安装版；便携包只包含 `portable.flag`。请保持两类目录分开，不要手工交换标记。

## 输入字符

首次主动启动时完成简短引导，并在输入测试区练习。测试区的文本只在内存中展示。平常使用步骤：

1. 在目标应用使用微软拼音输入，找到候选栏右侧的 U+ 按钮。
2. 点击 U+，或在候选栏中按 0 打开检索面板。当前未上屏的内容可按设置带入检索。
3. 输入英文名称、`U+2200` 形式的码位或中文数学别名。中文检索可先在别处输入后粘贴；直接在检索框内使用中文输入法仍需专门验证。
4. 面板每页显示五项。启用数字选字后，1–5 对应当前候选；显式码位查询仍允许继续输入数字。也可使用面板提供的选择与翻页操作。
5. 确认后检查目标应用中的实际结果。遇到发送结果不确定的提示时，先检查目标文本，避免重复插入。

字体可能缺少部分字符的字形。控制符、空白、组合字符、私用区及未分配码位使用可见码位占位显示；字符实际含义和目标应用显示效果仍由对应 Unicode 码位决定。

## 设置与托盘

设置页包含常规、输入与显示、自定义词条、关于与诊断。默认开启 U+ 按钮、0 唤起、带入未上屏内容和数字选字。主题默认跟随系统，字号提供小、默认、大预设。

托盘菜单用于设置、暂停/恢复、输入测试、帮助和退出。暂停会停止输入增强、清空临时缓冲并隐藏浮动按钮。关闭设置窗口后程序继续驻留；要结束运行，请使用托盘“退出”。

安装版可在常规设置中开启登录启动，启动时静默进入托盘。便携版关闭此入口。Windows 设置中的“应用 → 启动”也可禁用它；Winicode 尊重该选择。升级不会重新应用旧安装向导中的自启动勾选状态。

自定义词条包含字符或码位、触发词和中文说明。通过设置页增删改查及导入导出 JSON；导入会验证标量值、字段长度、数量与文件大小。导入前建议导出当前词条作备份。

## 升级、备份与卸载

安装版可运行较新的安装器，在原安装目录升级。安装器请求当前用户的 Winicode 正常退出，保留设置和别名，并阻止降级。退出失败时先从托盘退出后重试。便携版升级时先退出，将新包解压到新目录，再复制原 `userdata/`；保留旧目录作备份。

安装版个人数据位于 `%LOCALAPPDATA%\Winicode`：`settings.json`、`aliases.json` 和 `logs/` 分开存储。备份时先退出程序，再复制个人数据目录。配置异常时请先备份现状，再按[故障排查](troubleshooting.md)处理。

可从 Windows“已安装的应用”或开始菜单卸载。卸载默认保留个人数据；选择“同时删除个人设置、自定义词条、备份和日志”后会调用限定范围的应用清理命令。静默卸载始终保留个人数据。程序只删除安装时登记的程序文件与快捷方式，个人放入安装目录的其他文件会保留。

便携版退出后可手动删除解压目录。删除其中的 `userdata/` 会同时删除其设置和词条，请先备份需要保留的内容。
