# 隐私说明

Winicode 为提供微软拼音检索入口和输入增强，需要在当前用户会话中观察相关键盘事件、候选窗口及目标应用状态。当前未上屏的输入会短暂保存在内存中，用于打开检索面板时带入查询。暂停和退出会结束相应输入增强流程。

## 本地数据

安装版在 `%LOCALAPPDATA%\Winicode` 保存设置、自定义词条、配置恢复备份和受限日志；便携版在解压目录的 `userdata/` 保存这些内容。应用排除项保存进程标识，不保存完整窗口标题。自定义词条可能包含用户自行录入的敏感内容，导出或备份时请检查接收位置。

正常日志不记录按键、查询内容、剪贴板、输入测试文本或完整窗口标题。首次引导和输入测试只在内存中显示测试内容。诊断功能先提供预览，再由用户手动导出；预览隐藏原始异常消息和路径等信息。提交诊断前仍应自行审阅。

## 网络与更新

Unicode 数据随应用打包，核心字符检索和输入可离线工作。首版通过人工操作检查指定仓库 `th-1056/Winicode` 的 GitHub HTTPS 发布元数据，查询时网络服务会看到请求的来源 IP 和常规请求信息。手动打开项目或下载页时，浏览器会连接 GitHub。GitHub 的数据处理遵循其自身政策。

自动检查默认关闭。应用不会自动下载或执行更新，也不会自动上传诊断、设置、词条或输入内容。首次下载发布包、开发者构建时获取框架包，以及维护者刷新 Unicode 数据属于独立网络操作。

## 登录启动与删除

登录启动默认关闭。安装版开启后，在当前用户 HKCU Run 项中保存正确引用的可执行文件路径和 `--background`，并尊重 Windows 的禁用状态。便携版关闭自启动入口。

安装版卸载默认保留个人数据，静默卸载也保留数据。交互卸载时可明确选择同时删除设置、词条、备份和日志；应用会限定清理范围。删除前建议备份需要保留的词条。便携版的数据随自身 `userdata/` 目录存放，可在退出后手动删除。
